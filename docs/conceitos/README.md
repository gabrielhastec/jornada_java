# Fichas de conceito

Um arquivo por assunto que aparece no trabalho real e quase nunca é ensinado em curso ou faculdade. Toda ficha responde às mesmas 6 perguntas:

1. **Que problema real fez isso existir?**
2. **O que se fazia antes?**
3. **O que é, em uma frase?**
4. **Onde isso aparece num sistema** (qual camada, qual arquivo, qual anotação)
5. **Como eu erro isso na prática** (os erros clássicos)
6. **Como praticar** (laboratório em [`05-laboratorios/`](../../05-laboratorios/))
